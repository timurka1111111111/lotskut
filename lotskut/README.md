# Лоскут — маркетплейс handmade (Firebase)

Страницы: каталог, товар, корзина, вход/регистрация, продажа, профиль, избранное, лавка мастера, о нас, seed (заливка товаров).

## Запуск на компьютере
Нужен Node.js (https://nodejs.org). В папке сайта:
```
npm start
```
Открой http://localhost:3000. Двойным кликом по index.html открывать нельзя — модули не работают с file://.
(Без Node: `python -m http.server 3000` и http://localhost:3000)

## Настройка Firebase (один раз)
Конфиг в `js/firebase.js` уже вставлен. Осталось проверить в консоли https://console.firebase.google.com (проект lotskut):
1. **Build → Authentication → Sign-in method → Email/Password → Enable → Save.**
2. **Build → Firestore Database → Create database** (если ещё нет) → production mode.
3. **Firestore → вкладка Rules** → удали всё, вставь содержимое файла `firestore.rules` → **Publish**. Без этого товары не грузятся и заказы не оформляются.

## Наполнить каталог
1. Открой `http://localhost:3000/login.html#up`, зарегистрируйся.
2. Открой `http://localhost:3000/seed.html` → «Добавить 24 товара». Товары от 7 мастеров с картинками появятся в каталоге.
   (Пока база пуста, каталог и так показывает эти 24 демо-товара, но покупать можно только реальные.)
3. Свои товары: «Продать» → фото сжимается и хранится в базе.

## Проверка, что всё работает
- Регистрация/вход → в правом верхнем углу появляется имя.
- Товар → «Добавить в корзину» → Корзина → оформить заказ → он в «Мои покупки» в профиле.
- Заказ на товар мастера виден ему в профиле: «Заказы на мои изделия».

## Выложить в интернет
```
npx firebase-tools login
npm run deploy
```
Сайт будет на https://lotskut.web.app (деплоит и сайт, и правила). Перед деплоем удали `seed.html` и `js/seed.js`.

## Если что-то не работает
На странице появится код ошибки. `permission-denied` = не опубликованы правила (шаг 3). Подробности — в консоли браузера (F12).
